## Brand & Style

This design system establishes a high-velocity, precision-tuned visual environment tailored for next-generation developer platforms, algorithmic computing consoles, and creative coding studios. The aesthetic pairs raw computational discipline with an explosive, high-voltage creative energy.

The aesthetic philosophy fuses **High-Impact Cybernetic Glassmorphism** with **Technical Precision Brutalism**:
- Deep, absorbing obsidian substrates that remove ambient noise and spotlight mission-critical telemetry.
- Sharp, razor-fine luminescence: intense chromatic collisions between kinetic Electric Tangerine and atmospheric Cyber Violet.
- Utilitarian structural rigor: geometric micro-borders, functional monospaced data badges, and hard spatial rhythm that evokes advanced compiler outputs and high-end IDE terminals.
- Ambient refraction: translucent surface stacks with crisp 1px gradient rims simulating laser-etched anti-reflective optical glass.

## Colors

The palette operates on calibrated contrast tiers built specifically for deep dark mode environments, anchoring attention through chromatic hierarchy.

### Accent Roles
- **Primary Accent (`#FF5500` / Electric Tangerine):** Used for critical call-to-actions, active telemetry triggers, execution prompts, and breaking anomalies. Carries a vibrant, high-energy footprint.
- **Secondary Accent (`#8B5CF6` / Cyber Violet):** Used for background aura blooms, computational state markers, selection states, secondary interactive nodes, and system synthesis alerts.
- **Tertiary Accent (`#F8FAFC` / Pure Ice White):** Pinned for high-priority headlines, key values, active input foregrounds, and razor specular reflections.

### Dark Substrates & Structural Scales
- **Base Canvas (`#090A0F`):** The absolute background void, maximizing dynamic range.
- **Layer 1 Surface (`#111218`):** Base structural container color for sidebars, canvas frames, and sunken consoles.
- **Layer 2 Card / Float (`#1A1B24`):** Elevated modules, floating panels, dropdown menus, and active card substrates.
- **Surface Highlight (`rgba(248, 250, 252, 0.05)`): Subtle translucent sheen applied to active cards.
- **Borders & Seams:**
  - Ghost: `rgba(248, 250, 252, 0.08)`
  - Active / Focus: `rgba(255, 85, 0, 0.6)`
  - Secondary Glow: `rgba(139, 92, 246, 0.45)`

## Typography

The typographic hierarchy enforces strict distinction between editorial punch, continuous text readability, and scientific telemetry data.

- **Headlines (`Space Grotesk`):** Chosen for its aggressive geometric proportions, idiosyncratic hooks, and brutal digital attitude. Sets the tone for heroic statements and module headers.
- **Body & Continuous Copy (`Inter`):** Highly legible, neutral workhorse engine. Balances out the punch of the headlines, ensuring long sessions of documentation reading and log auditing avoid eye fatigue.
- **Code, Metadata & Badges (`Space Mono`):** Fixed-pitch clarity for timestamps, Git commit shas, payload indicators, and micro-labels. Capitalized micro-labels utilize explicit tracking (`+0.08em`) to guarantee scanability across low-luminosity cards.

## Layout & Spacing

This design system uses an **8-point geometric baseline grid** with a tight **4-point micro-scale** for precision metadata tags, code inspectors, and compacted sidebars.

### Grid Architecture
- **Desktop (1280px+):** 12-column fluid grid. Gutters pinned to `2rem` (32px), outer safety margins to `3.5rem` (56px). Split-screen console panes adhere strictly to 50/50 or asymmetric 60/40 terminal/preview columns.
- **Tablet (768px - 1279px):** 8-column layout. Gutters reduced to `1.5rem` (24px); navigation collates into a persistent glass rail.
- **Mobile (< 768px):** 4-column stack. Margin and gutters normalize to `1rem` (16px). Multi-column code tools reflow into tabbed horizontal scroll stages.

### Rhythmic Density
- Density is tightly controlled: dense for terminal tools, logs, and schema explorers; generous for product overviews and showcase landing dashboards.

## Elevation & Depth

Depth is not rendered through muddy black drop-shadows; it is achieved through **ambient glassmorphism, luminous back-glows, and laser-thin specular light edges**.

### The Layer Stack
1. **Floor 0 (Root Canvas `#090A0F`):** Deepest void layer. Underlays diffuse radial gradient light sources (`rgba(139, 92, 246, 0.08)` and `rgba(255, 85, 0, 0.06)`).
2. **Floor 1 (Structural Modules `#111218`):** Non-elevated containers with `1px solid rgba(248, 250, 252, 0.06)`.
3. **Floor 2 (Floating Glass `#1A1B24` with 80% opacity and `backdrop-filter: blur(16px)`):** 
   - Border: 1px top-highlight border via linear-gradient (`to bottom, rgba(248, 250, 252, 0.18), rgba(248, 250, 252, 0.03)`).
   - Shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.6)`.
4. **Floor 3 (Active Interactivity / Flyouts):**
   - Electric Border: 1px perimeter saturated with `rgba(255, 85, 0, 0.5)` or `rgba(139, 92, 246, 0.6)`.
   - Volumetric Radiance: `0 0 24px -2px rgba(255, 85, 0, 0.25)` or Cyber Violet wash `0 0 32px -4px rgba(139, 92, 246, 0.3)`.

## Shapes

The shape vocabulary prioritizes **sharp, industrial, technical precision**. Soft bubbles and heavy circular geometry are avoided.

- Base UI components (buttons, input fields, badges, cards) use an intentional **0.25rem (4px)** corner radius (`roundedness: 1`), keeping the visual cadence strict and engineered.
- Card containers and modals step up to **0.5rem (8px)** (`rounded-lg`) to balance perimeter scale without softening the brutalist silhouette.
- Large floating sheets max out at **0.75rem (12px)** (`rounded-xl`).
- Micro-dividers and selection indicators maintain crisp, squared terminal ends (`0px`).

## Components

### Buttons
- **Primary (Electric Tangerine Glow):**
  - Background: `#FF5500`. Text: `#090A0F` (heavy bold `Space Mono` or `Inter`, 600 weight).
  - Hover: Background lightens to `#FF6A1A`; box-shadow yields `0 0 20px rgba(255, 85, 0, 0.45)`.
  - Border: None. Height: 40px (Desktop), 36px (Compact).
- **Secondary (Cyber Glass):**
  - Background: `rgba(26, 27, 36, 0.7)` with `backdrop-filter: blur(12px)`. Text: `#F8FAFC`.
  - Border: 1px solid `rgba(139, 92, 246, 0.4)`.
  - Hover: Border color snaps to `#8B5CF6`; box-shadow yields `0 0 16px rgba(139, 92, 246, 0.3)`.
- **Tertiary / Ghost:**
  - Background: Transparent. Text: `#94A3B8`.
  - Hover: Background: `rgba(248, 250, 252, 0.05)`; Text: `#F8FAFC`.

### Chips & Badges
- Strict monospaced typography (`Space Mono`, 11px, bold, uppercase).
- Height: 22px; Padding: `0 8px`; Radius: 2px - 4px.
- **Tangerine Status:** Background `rgba(255, 85, 0, 0.12)`, text `#FF5500`, border `1px solid rgba(255, 85, 0, 0.3)`.
- **Violet Metadata:** Background `rgba(139, 92, 246, 0.12)`, text `#A78BFA`, border `1px solid rgba(139, 92, 246, 0.3)`.

### Cards & Panels
- Background: Glass-morphic `#1A1B24` (85% opacity) with 1px hairline border (`rgba(248, 250, 252, 0.08)`).
- Card Top Edge: Subtle inner highlight `box-shadow: inset 0 1px 0 0 rgba(248, 250, 252, 0.15)`.
- Hover State: Border switches to `rgba(255, 85, 0, 0.4)` accompanied by a smooth, deep upward translate (`-2px`).

### Input Fields
- Background: `#111218`. Text: `#F8FAFC` (`Inter` 14px or `Space Mono` for technical parameters).
- Inactive Border: `1px solid rgba(248, 250, 252, 0.12)`.
- Focus State: Border snaps to `#FF5500` with an omni-directional aura `box-shadow: 0 0 0 2px rgba(255, 85, 0, 0.2)`. Placeholder: `#475569`.

### Checkboxes & Radio Buttons
- Form factor: Box (4px radius) and Circle (full radius) respectively, 16px diameter.
- Unchecked: Background `#111218`, Border `1px solid rgba(248, 250, 252, 0.2)`.
- Checked: Background `#FF5500`, Border `#FF5500`, containing an Ice White (`#F8FAFC`) centered glyph or core. Outer ring glow on focus.

### Code Terminals & Telemetry Logs
- Background: `#090A0F` with embedded vertical scanlines via background-gradient SVG overlay.
- Syntax highlighting: Variables in `#F8FAFC`, functions/methods in `#8B5CF6`, triggers/keywords in `#FF5500`, strings in `#38BDF8`.
